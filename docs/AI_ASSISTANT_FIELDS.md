# AI assistant field and state knowledge

Date: 2026-11-14. Runtime help is compiled by `build_assistant_knowledge.py`. Field aliases match the page; generation fails when a new literal Field is uncovered. Dynamic processing parameters take their help and defaults from the parameter declarations in `api/meta.py` and are not maintained twice.

| ID | Field aliases | Meaning and effect | Default source and constraints | Topic |
|---|---|---|---|---|
| field.model | Model; Input model | Select a complete HF/NVFP4 directory or a GGUF file, or give an explicit HF repository; determines later architecture identification and route | Means the PC running the service; quotes/leading-trailing spaces from a copied address are supported. For a complete HF fill only this field; for GGUF pick the specific file; a path existing does not mean the format is supported; the path is not sent to the external assistant | input |
| field.original | Original model source; Original HF directory | Supplies the matching config, tokenizer, or full-precision tensors required by the route for an already-quantized source | Shown by default; leave empty for a complete HF model; required when the source is missing. The supported self-contained Qwen3.5-0.8B Q8_0 GGUF generates config/tokenizer/template automatically and needs no source; a traditional GGUF source directory needs config.json and tokenizer.json/tokenizer.model, and a directory containing only GGUF cannot be selected; explicit repository links are supported; the source is never guessed from the file name and never depends on the developer's local directory | input |
| field.gguf | Repository GGUF file | Pick the specific file and shards in a multi-precision repository; the input precision follows the file | The user chooses explicitly; precision is never guessed | input |
| field.output | Output directory | Stores new artifacts, plans, logs, and reports; intermediate files may take more space | Assigned automatically or chosen by the user as a new empty directory outside the original model; source weights are never overwritten | resources |
| field.target | Target bit width; Quantization plan; Quantization target | Choose the quantization target directly: plan options state the bit width, algorithm, and engine; the bit-width dropdown only filters by main-weight precision; there is no longer a "usage preference" that silently picks a plan for the user | Candidates = verified recipes for the current model + engine; unadapted bit widths are not listed, so the menu may be short; auto recommendation is a usable default following the model's default policy, not a guarantee of optimality; lower bits do not guarantee more speed or unchanged quality | quantization |
| field.ternary | Published ternary GGUF | A ready-made PQ2_0 source matching Bonsai 2; no new ternary model is trained | Optional; required when that recipe is enabled; architecture/geometry must match | quantization |
| field.device | Conversion device | Controls whether conversion computes on CUDA or a supported CPU route; it does not change the inference engine | From meta.defaults.device; CPU routes have no uniform speed measurement | resources |
| field.requantization | Allow approximate requantization | Expresses the user's explicit consent to the loss of approximately decoding and requantizing already-quantized weights; lost information is not restored | Off by default; it cannot lift real limits such as unadapted formats/architectures | quantization |
| field.jailbreak | Abliteration method | none keeps existing weight behavior; Abliteration/Heretic rewrites supported full-precision weights and may affect task quality | Default none; imported quantized weights cannot be processed again; Heretic needs an interactive save | calibration |
| field.calibration_file | Calibration corpus | UTF-8 text used by AWQ/GPTQ to estimate quantization statistics; representativeness affects results and time | Leave empty to prepare WikiText-2 train at the current pinned revision; never mixed with evaluation data | calibration |
| field.group | Group size | One group of weights shares quantization parameters, affecting metadata overhead, statistics, and compatibility | Current new-calibration default 128, options 32/64/128; existing packed layouts follow their own contract | calibration |
| field.samples | Calibration samples | Number of calibration samples; more may increase time, memory, and data coverage, but quality is not guaranteed to improve monotonically | Current HF default 128; the allowed range is validated by the backend | calibration |
| field.sequence | Tokens per sample | Length of each calibration sample; affects activation scale and usable corpus | Current HF default 512; cannot exceed the model's actual window; short samples never silently switch the algorithm | calibration |
| field.backend | HF inference backend | torch uses compatible compute; auto lets GPTQModel choose, and some optimized kernels need extra build tools | Default torch; HF runs in an isolated environment; quantized packed weights are not handed to NInfer | serving |
| field.speculative | Speculative decoding | Uses compatible existing MTP/DFlash2 components; when disabled, heads that should be kept are still kept | Default auto; an explicit request without the component is refused. HF does not run heads; auto with heads blocks the route | speculation |
| field.context | Serving context | The token window used by input, generation, and cache; larger values raise VRAM pressure | The effective value comes from the runtime profile; geometry/engine caps cannot be broken by typing a bigger number | serving |
| field.concurrency | Max concurrency | Number of simultaneous requests; affects cache/compute resources and throughput | Takes the meta/runtime default; HF generation currently requires 1 | serving |
| field.port | Serving port | The listen port of the local model API on this PC; different from the page/external assistant service address | Default takes the port of the first origin in TURBOFORGE_AI_ALLOWED_LOCAL_ORIGINS in .env (template 18080); 1–65535 and not in use; changes take effect through the existing plan/script flow | serving |
| field.smoke | Post-conversion smoke test | A real GPU load plus a short generation provides runnable evidence; it does not replace a full quality evaluation | Enabled by default; HF cannot skip it. converted must not be treated as validated | quality |
| field.benchmark | Benchmark speed; Post-conversion speed benchmark (quality evaluation optional) | Runs the real speed/optional PPL test supported by the current route, adding time; when off, unmeasured means unknown | From the current user choice/guided-mode default; the gate depends on the corresponding evaluation | performance |
| field.repetitions | Benchmark repetitions | Repeated tests help observe variance and also add time | Current default and range come from benchmark/profile; HF has a repetition limit and never reruns infinitely by default | performance |
| field.kv | Benchmark KV precision | Affects only the test cache/runtime numerics and VRAM; it does not change the main-weight encoding | Follows geometry automatically; bf16/rk4v4 speed and quality must be verified on the corresponding engine | performance |
| field.eval_text | Evaluation corpus; Perplexity text | Scores on the given UTF-8 text; new HF quantization may leave it empty to use the pinned test set automatically, up to 2048 tokens | Kept separate from calibration train; NInfer needs a manual corpus and baseline; full paths are excluded by default | quality |
| field.eval_manifest | Perplexity corpus manifest | Uses a supported scored-corpus description instead of ordinary free text | Chosen against Perplexity text under the existing contract; must be valid and version-consistent | quality |
| field.baseline | Baseline model; Baseline artifact | A baseline with the same source/tokenizer/processing stage is used to measure the difference | NInfer users provide a verified baseline; HF currently uses this run's post-processing full-precision CPU FP32 reference; packed weights cannot prove themselves lossless | quality |
| field.ppl_gate | Quality gate | Requires the PPL comparison to pass before a direct start; a failed measurement must not be disguised as a pass | On by default for guided-mode new HF quantization and can be explicitly turned off; NInfer follows the user choice; it cannot replace code/math/long-text evaluation | quality |
| field.ppl_threshold | Allowed PPL increase | The user's acceptance threshold for the relative increase `(current/baseline - 1)×100%`; not an official safety guarantee | The page's common initial value is 10%, decided by the user's task requirements; editing the manifest to bypass a failure is not allowed | quality |
| field.prompt_lengths | Prefill length list | Benchmark input token lengths; affect prefill load and measurement comparability | From profile/benchmark; comma-separated valid lengths, bounded by geometry caps | performance |
| field.generation_lengths | Generation length list | Benchmark output token counts; affect decode time and the test basis | Takes the current profile/user values; HF does not support arbitrary numbers of generation lengths | performance |
| field.ppl_context | Perplexity context | The PPL scoring window length; not the quantization bit width or training length | Bounded by the model's actual window; the baseline must use the same effective value | quality |
| field.ppl_stride | Perplexity stride | The scoring sliding-window step; affects overlap and the number of scores | Greater than 0 and less than the actual PPL context; baseline conditions match, and repeated counting must not pose as new corpus | quality |
| field.bench_ids | Benchmark corpus ids | A token-ID corpus used by a specific tool to generate a reproducible load | Uses the current compatible format; acceptance on a tiled corpus does not represent real user requests | performance |
| field.upstream | NInfer converter source directory | Matched source containing tools/convert; the origin of the converter program | Prepared automatically or chosen by the user at a pinned revision; a different revision needs a compatibility check | maintenance |
| field.engine | NInfer engine directory | Contains ninfer.exe/ninfer-serve.exe and DLLs; affects actual load/generation support | Prepared automatically or chosen as a matching bundle; conversion support does not mean the engine supports running | maintenance |

## Build and serving states

| ID | Name | Meaning and next step | Can start directly |
|---|---|---|---|
| state.idle | idle / created / starting / planned | Waiting, starting, or planned; the artifact is not yet proven runnable — see the next stage | No |
| state.preparing | preparing | Downloading/installing and preparing files; see the current preparation log | No |
| state.processing | jailbreaking / jailbroken / converting | Weight processing or conversion in progress; finished processing is not finished GPU validation | No |
| state.converted | converted | The artifact was generated; this run has not completed the corresponding GPU validation | No |
| state.validating | validating / benchmarking | Validating or measuring; wait for real results — progress is not a score | No |
| state.validated | validated | This build passed validation; backend conditions such as task completion, the quality gate, and artifact/component checks still apply | Subject to the actual backend start gate |
| state.blocked | blocked / failed / crashed / interrupted | Blocked by planning, build failed, or interrupted; see the specific diagnostic/stage — editing the state file to bypass is not allowed | No |
| state.validation_failed | validation-failed | GPU load/generation validation failed; check the actual smoke log | No |
| state.quality_rejected | quality-rejected | The current quality requirement failed or evaluation failed; check the source, corpus, baseline, and actual metrics | No |
| state.server_starting | server: starting | The process is loading; the health check has not passed yet — see serve.log | Wait for ready |
| state.server_ready | server: ready | The local model health check passed; the next step is still one real text request | Running; not a guarantee of task quality |
| state.server_stopped | server: stopped / exited | Not running or the process exited; confirm the current build validation and service errors | Not running |
